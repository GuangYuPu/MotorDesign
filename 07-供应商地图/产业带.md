## 二、按品类

### 硅钢 / 电工钢
- 宝钢、太钢、首钢、鞍钢、马钢
- 进口：JFE、新日铁、蒂森克虏伯
- 采购特点：小批量常需整卷（数百 kg），薄料/特殊牌号交期长

### 冲片 / 铁芯
- 信质集团（台州）、通达动力（南通）、神力股份（常州）、东睦（宁波，SMC）、卧龙（上虞）
- 打样：淘宝/1688 线切割，或本地模具厂
- 关键能力：最小齿宽、叠压系数、毛刺控制

### 钕铁硼 / 磁组件
- 中科三环（北京）、宁波韵升（宁波）、正海磁材（烟台）、金力永磁（赣州）、大地熊（合肥）、英洛华（东阳）、宁波合力、京磁（北京）、包钢稀土（包头）
- 关键能力：牌号覆盖、镀层、多极充磁、异形加工、磁性能一致性
- **宁波是首选**：磁材 + 镀层 + 精加工 + 充磁，一小时内能跑完

### 漆包线
- 精达（铜陵）、露笑（诸暨）、金杯电工（长沙）、长城科技、蓉胜超微
- 关键能力：耐电晕线、自粘线、扁线、细线

### 绝缘材料 / 浸漆 / 灌封
- 艾伦塔斯 ELANTAS、苏州巨峰、浙江荣泰、杜邦、3M、汉高、回天新材
- 关键能力：耐温等级、与漆包线的兼容性、导热系数

### 轴承
- 人本（温州）、五洲新春（新昌）、洛阳LYC
- 进口：NSK、SKF、NTN、舍弗勒
- 关键：游隙、预紧、**轴电流防护**（陶瓷球/导电刷）

### 机加工 / 压铸
- 长三角、珠三角普遍
- 关键：同轴度、轴承位公差、压铸气孔

### 测试 / 第三方
- 各地质检院、上海电器科学研究所、CQC
- 用途：型式试验、能效备案、出口认证

## 三、找供应商的六条渠道（按效率排序）

| # | 渠道 | 效率 | 说明 |
|---|---|---|---|
| 1 | **同行 / 前同事转介绍** | ★★★★★ | 成功率最高，还能顺便问到真实评价 |
| 2 | **展会** | ★★★★☆ | 一天扫完一条链，能看到谁在给谁供货 |
| 3 | **产业带实地跑** | ★★★★☆ | 一次比看一百篇文章有用 |
| 4 | **让 A 供应商推荐 B** | ★★★★ | 供应商之间互相知道底细 |
| 5 | **1688 / 阿里巴巴** | ★★★ | 适合找打样和中小厂，需自己筛 |
| 6 | **企查查/天眼查按产业带搜** | ★★☆ | 适合补全名单，看不到能力 |

### 展会（重点）

| 展会 | 地点 | 覆盖 |
|---|---|---|
| CWIEME 中国国际电机博览会 | 上海 | 线圈、绝缘、磁材、铁芯、设备，**最垂直** |
| 深圳国际小电机及电机工业展 | 深圳 | 微电机、无刷、驱动 |
| 中国国际工业博览会 | 上海 | 综合，含电机与自动化 |
| CWIEME Berlin | 德国 | 国际供应链 |

### 淘宝 / 1688 的正确用法

| 可以 | 不可以 |
|---|---|
| 打样验证"能不能做出来" | 拿它的价格做成本模型 |
| 问"这个公差能做到多少" | 拿它的性能数据做设计定型 |
| 找小批量特殊规格 | 直接用于量产（无过程控制、无一致性） |
| 快速试错 | 作为唯一供应商 |

## 四、验厂清单（打印出来带着走）

**资质**
- [ ] 营业执照、经营范围是否匹配
- [ ] ISO9001 / IATF16949 证书（看有效期和认证范围）
- [ ] 是否有给同行/知名客户供货的记录

**设备**
- [ ] 关键设备型号、吨位、精度、数量
- [ ] 设备新旧程度、稼动率
- [ ] 有没有你需要的特殊工艺（如 VPI 罐、多极充磁机）

**检测能力**
- [ ] 三坐标、影像仪
- [ ] 磁性能（BH 仪 / 表磁）
- [ ] 耐压 / 匝间
- [ ] 动平衡
- [ ] 盐雾 / 高低温箱

**过程控制**
- [ ] 有没有作业指导书（SOP）
- [ ] 有没有首件检验记录
- [ ] 不良率数据（敢不敢给）
- [ ] 有没有追溯体系（批次/炉号）

**现场观感**
- [ ] 5S 水平
- [ ] 在制品堆放
- [ ] 工人操作是否规范
- [ ] 有没有返修区，返修品多不多

## 附：一句话记住

> 找供应商不是"认识更多人"，是**建立一张"谁能做什么、做到什么程度、要多少钱"的地图**。
> 地图越细，你设计时的自由度越大。
