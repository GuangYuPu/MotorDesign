# 速查卡 · 漆包线

> 设计槽满率时，**必须用漆膜外径，不是裸铜径**。这一条错了，整台电机的槽满率、温升、可制造性全部重算。

---

## 1. 型号怎么读

```
Q ZY - 2 / 180
│  │   │    └── 温度等级（℃）
│  │   └────── 漆膜厚度等级：1 / 2 / 3（3 最厚最耐）
│  └────────── 漆膜类型
└───────────── Q = 漆包线
```

| 代号 | 漆膜类型 | 温度等级 | 特点 | 价格 |
|---|---|---|---|---|
| QZ | 聚酯 | 130（B） | 便宜，耐热差，耐溶剂一般 | 基准 |
| QZY | 聚酯亚胺 / 聚酰胺酰亚胺复合 | 180（H） | **电机最常用**，综合性能好 | +15% |
| QZY | 同上 | 200（C） | 高耐热 | +25% |
| QY | 聚酰亚胺 | 220 | 耐热最好，贵 | +60% |
| Q(ZY/XY) | 耐电晕复合 | 200 | **变频电机必选** | +50~120% |
| QZY-SB | 自粘 | 180 | 绕后热熔自粘成型 | +40% |

## 2. 漆膜厚度与外径（槽满率计算的关键）

**外径 = 裸铜径 + 双边漆膜增量**

| 裸铜径 (mm) | 1 级增量 | 2 级增量 | 3 级增量 |
|---|---|---|---|
| 0.20 | ~0.024 | ~0.032 | ~0.040 |
| 0.30 | ~0.028 | ~0.038 | ~0.048 |
| 0.40 | ~0.032 | ~0.044 | ~0.056 |
| 0.50 | ~0.036 | ~0.050 | ~0.064 |
| 0.63 | ~0.042 | ~0.056 | ~0.072 |
| 0.80 | ~0.048 | ~0.064 | ~0.082 |
| 1.00 | ~0.056 | ~0.072 | ~0.092 |
| 1.20 | ~0.064 | ~0.080 | ~0.104 |

> **上表是量级参考**，用于快速估算。正式设计请查 **GB/T 6109.1** 或供应商的漆膜厚度表，并按**上限**取值（保守）。

**标准说法**：标称 `QZY-2/180 φ0.50` 一般指裸铜径 0.50 mm，2 级漆膜，最大外径约 0.55 mm。

## 3. 耐电晕（变频电机的生死线）

**问题**：变频器 PWM 输出 dv/dt 可达 **5~20 kV/μs**，长线缆反射后端子电压可达母线电压的 **2 倍**。高频脉冲反复冲击漆膜，局部放电逐步侵蚀，几百到几千小时后匝间击穿。

**对策（按优先级）**：

| 措施 | 效果 | 成本 |
|---|---|---|
| 用耐电晕漆包线（漆膜掺纳米 TiO₂/Al₂O₃） | 寿命提升数十倍 | +50~120% |
| 加 dv/dt 滤波器 / 输出电抗器 | 显著降低尖峰 | 中 |
| 缩短线缆 / 降低载波频率 | 有限 | 低 |
| 提高绝缘等级（3 级漆膜、加厚槽绝缘） | 有限 | 低 |

**认证依据**：**IEC 60034-18-41**（变频供电电机的绝缘系统资格认证）。客户要"变频专用"时，问他要不要这个认证。

## 4. 特殊线材

| 类型 | 用途 | 关键点 |
|---|---|---|
| 自粘线 | 无骨架绕组、绕后自粘成型 | 需控制烘焙温度曲线；返修困难 |
| 利兹线 Litz | 高频（≥1 kHz），降低集肤效应 | 单股 0.05~0.1 mm；填充系数仅 0.3~0.5；需热剥/化学剥漆后焊接 |
| 扁线（发卡） | 高槽满率（70~75%） | 设备投入大；端部交流损耗需专门核算；焊接质量是命门 |
| 复合线（铜包铝） | 降本、轻量 | 电阻高、焊接难、可靠性争议大 |
| 漆包绞线 | 大截面柔软 | 绞合节距影响填充 |

## 5. 槽满率的两个口径（谈之前必须说清）

| 口径 | 定义 | 典型可达值 |
|---|---|---|
| **净槽满率** | 铜总截面 ÷（净槽面积 − 槽绝缘 − 槽楔） | 圆线 40~45%，高手 45~50% |
| **毛槽满率** | 铜总截面 ÷ 毛槽面积 | 圆线 32~38% |
| 扁线净槽满率 | | 70~75% |

> 说"我做到 55%"之前，先确认是哪个口径。这一句话能瞬间分辨对方是不是内行。

## 6. 采购

| 项 | 常规 |
|---|---|
| MOQ | 25~100 kg / 规格（小厂可谈更低） |
| 线盘重量 | 1~30 kg/盘（细线小盘，粗线大盘） |
| 交期 | 常规 2~3 周，特殊 4~6 周 |
| 认证 | UL（OBMW2/8）、RoHS、REACH |
| 计价 | 元/kg，随铜价浮动，报价有效期常 1~2 周 |

**到货必检**：

| 项 | 方法 | 判据 |
|---|---|---|
| 线径 | 千分尺，多点（0° / 90°） | 在 GB/T 6109 公差内 |
| 直流电阻 | 每米电阻 / 电桥 | 换算 20℃ 电阻率 ≤ 0.017241 Ω·mm²/m × (1+容差) |
| 伸长率 | 拉伸试验 | 一般 ≥ 25~30% |
| 击穿电压 | 扭绞法 / 钢珠法 | 按等级 |
| 附着性 | 卷绕 / 拉伸后看漆膜 | 不开裂、不脱落 |
| 耐溶剂 | 丙酮/酒精擦拭 | 不软化 |

**常被忽略的一条**：线径公差**偏下**会导致电阻偏大 → 铜损偏高温升偏高。所以电阻测试比线径测试更能反映实际问题。

## 7. 常见坑（按踩坑频率排序）

| # | 坑 | 后果 | 规避 |
|---|---|---|---|
| 1 | 槽满率用裸铜径算 | 实际绕不进去，或强行绕导致漆膜损伤 | 一律用最大外径 |
| 2 | 变频电机用普通漆包线 | 数百小时后匝间击穿 | 耐电晕线 + IEC 60034-18-41 |
| 3 | 漆膜等级选低了 | 耐压不过、嵌线时破漆 | 2 级起步，高压/大电流用 3 级 |
| 4 | 忽略线头损耗 | 材料成本低估 3~5% | 单独列损耗率 |
| 5 | 自粘线烘焙曲线照抄 | 粘不牢或过烘变脆 | 按厂家曲线做小样验证 |
| 6 | 利兹线去漆不净 | 焊点电阻大、发热 | 热剥 + 焊前检查 |
