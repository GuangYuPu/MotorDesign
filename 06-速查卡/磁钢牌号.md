# 速查卡 · 永磁材料

> 规则：**所有数字都是"常规量级参考"，签合同前必须以供应商 datasheet + 你自己实测为准。**
> 尤其磁性能，标称值和实测值差 3~5% 是常态。

---

## 1. 钕铁硼牌号怎么读

```
N 42 SH
│  │  └── 内禀矫顽力等级（耐温等级）
│  └───── 最大磁能积 (BH)max 标称值，单位 MGOe
└──────── 钕铁硼 NdFeB
```

- **42 MGOe ≈ 334 kJ/m³**（1 MGOe ≈ 7.96 kJ/m³）
- 牌号里的数字是**标称值**，行业惯例最小保证值 = 标称 - 2 MGOe

## 2. 耐温等级（这是选材的第一决定因素）

| 等级 | Hcj 下限 (kA/m) | 常规最高工作温度 | 相对价格 | 典型场景 |
|---|---|---|---|---|
| N | ≥ 955 | ~80 ℃ | 1.0 | 风机、消费品、低温场景 |
| M | ≥ 1114 | ~100 ℃ | 1.05 | |
| H | ≥ 1353 | ~120 ℃ | 1.15 | 一般工业电机 |
| SH | ≥ 1592 | ~150 ℃ | 1.3 | 伺服、电动车、常见主力 |
| UH | ≥ 1990 | ~180 ℃ | 1.5 | 高功率密度、油冷 |
| EH | ≥ 2388 | ~200 ℃ | 1.8 | 极端工况 |
| AH | ≥ 2786 | ~230 ℃ | 2.2 | 航空、特殊 |

> **警告：这张表的"最高工作温度"是行业经验值，不是物理定律。**
> 真实可用温度由**工作点 Pc（磁导系数）**决定。磁钢越厚、气隙越小、Pc 越大，同样的牌号能扛更高温度。
> 薄磁钢 + 大气隙 + 高去磁电流 → 可能要跳两级牌号。
>
> 注意：N/M/H/SH 这套等级只用于**烧结**钕铁硼；**粘结钕铁硼不套这个体系**，按 (BH)max 分档，见 7.3。

## 3. 常用牌号典型 Br（20℃）

| 牌号 | Br 典型 (T) | (BH)max 最小 (kJ/m³) |
|---|---|---|
| N35 | 1.17 ~ 1.21 | 263 |
| N38 | 1.22 ~ 1.26 | 287 |
| N40 | 1.26 ~ 1.29 | 302 |
| N42 | 1.29 ~ 1.32 | 318 |
| N45 | 1.32 ~ 1.38 | 342 |
| N48 | 1.37 ~ 1.42 | 366 |
| N50 | 1.40 ~ 1.45 | 382 |
| N52 | 1.43 ~ 1.48 | 398 |

**注意**：高牌号（N50/N52）通常只能配到 H 级左右，**高磁能积和高矫顽力在工艺上是矛盾的**（需要更多重稀土 Dy/Tb，成本飙升）。所以"N52UH"这种组合要么不存在，要么非常贵。

## 4. 温度系数（用来做高温校核）

| 参数 | 典型值 | 用法 |
|---|---|---|
| αBr | -0.11 ~ -0.12 %/℃ | Br(T) = Br₂₀ × [1 + αBr × (T-20)/100] |
| βHcj（N~H） | -0.50 ~ -0.60 %/℃ | 高温 Hcj 下降快 |
| βHcj（SH~UH） | -0.45 %/℃ 左右 | 重稀土改善 |
| βHcj（EH~AH） | -0.40 %/℃ 左右 | |

**算例**：N42SH，Br₂₀ = 1.30 T，Hcj₂₀ = 1592 kA/m，工作在 150℃
- Br₁₅₀ ≈ 1.30 × [1 - 0.115 × 1.30] ≈ **1.11 T**
- Hcj₁₅₀ ≈ 1592 × [1 - 0.45 × 1.30] ≈ **660 kA/m** ← 掉了一半多，这就是退磁风险的来源

## 5. 退磁校核流程（必须按这个顺序做）

```
1. 定最恶劣工况
   ├─ 最高工作温度（不是环境温度，是磁钢实际温度）
   ├─ 最大去磁电流（弱磁点 / 三相短路 / 堵转）
   └─ 最恶劣电流角（通常是 d 轴去磁方向）
2. 求工作点
   ├─ 算 Pc = Bd / (μ₀ × Hd)
   ├─ 在第二象限 B-H 图上画 Pc 线
   └─ 与该温度下的退磁曲线求交点
3. 判据
   ├─ 交点在膝点以上 → 可逆，安全
   └─ 交点在膝点以下 → 不可逆退磁，必须改设计
4. 改设计的手段（按代价从低到高）
   ├─ 降低磁钢温度（导热胶、油冷、降低损耗）
   ├─ 增加磁钢厚度（提高 Pc）
   ├─ 升牌号（H → SH → UH）
   ├─ 磁钢端部倒角 / 分段（改善端部工作点）
   └─ 增加隔磁 / 调整极弧系数
```

**必做两张图**：20℃ 一张、Tmax 一张。只做常温那张，是最常见的翻车方式。

## 6. 镀层

| 镀层 | 耐蚀性（中性盐雾 NSS） | 成本 | 备注 |
|---|---|---|---|
| NiCuNi（镍铜镍） | 24~72 h | 基准 | 最常用，导电，可焊性差 |
| 环氧 Epoxy | 96~480 h | +10~30% | 高防腐、高绝缘，适合湿热/盐雾环境 |
| 锌 Zn | 12~48 h | 低 | 便宜，但耐蚀一般 |
| 磷化 | 差 | 低 | 多为过渡层 |
| 锌铝 ZnAl | 好，耐高温 | 中 | 高温场景 |

> 盐雾要求一定要写清标准和时间（如"GB/T 10125 中性盐雾 96h 无红锈"），只写"防腐"等于没写。

## 7. 永磁材料横向对比：铁氧体 / 粘结钕铁硼 / 烧结钕铁硼

### 7.1 一张表看完

| 项目 | 烧结铁氧体 Y33/Y35 | 粘结钕铁硼 | 烧结钕铁硼 N35~N48 |
|---|---|---|---|
| Br（T） | 0.40~0.45 | 0.45~0.60（各向同性）；0.60~0.75（各向异性） | 1.15~1.42 |
| (BH)max（kJ/m³） | 28~38 | 35~80 | 260~420 |
| Hcj（kA/m） | 240~350 | 600~1200 | 950~2400 |
| 最高工作温度 | **200~250℃** | **100~180℃**（看粘结剂） | 80~220℃（看牌号） |
| αBr | −0.20 %/℃ | −0.10~0.12 %/℃ | −0.11~0.12 %/℃ |
| βHcj | **+0.3~0.6 %/℃** | −0.4~0.5 %/℃ | −0.5~0.6 %/℃ |
| 电阻率 | >10⁶ Ω·m（绝缘） | 比烧结高几个数量级 | 1.4~1.6 μΩ·m |
| 密度（g/cm³） | 4.8~5.1 | 5.0~6.2 | 7.4~7.6 |
| 耐蚀 | 不锈 | 不锈（粘结剂包覆） | 必须镀层 |
| 成型 | 压坯 + 磨，简单形状 | **注塑/压制，磁环、多极、复杂形状** | 压坯 + 磨，简单形状 |
| 参考价（元/kg） | 10~20 | 80~200 | 250~500 |

> 数字性质：厂商样本典型值 + 行业经验值；不同厂、不同牌号能差 20~30%。

### 7.2 三个本质区别

**① 磁能积差一个数量级。** 铁氧体 30 → 粘结 50~80 → 烧结 300+（kJ/m³）。同体积，烧结的磁通是铁氧体的 3 倍以上；粘结只有铁氧体的 1.5~2 倍、烧结的 1/4~1/3。**所以粘结磁体的磁钢要厚（3~6mm），气隙磁密通常只有 0.4~0.6 T。**

**② 温度方向相反。** 铁氧体的 Hcj 随温度**升高**（+0.3~0.6%/℃），高温反而不容易退磁；两种钕铁硼的 Hcj 都随温度**下降**，高温 + 大去磁电流是最危险的组合。

**③ 成型方式决定设计自由度。** 铁氧体和烧结只能磨简单形状，公差 ±0.05~0.1；**粘结可以注塑成整体磁环、带定位特征、甚至包胶到转子壳上**，公差 ±0.05。

### 7.3 粘结钕铁硼：买的是"形状 + 轻"，不是磁性能

**是什么**：NdFeB 粉末 + 粘结剂（尼龙 / PPS / 环氧），注塑或压制。注塑适合复杂形状/大批量，压制磁性能更高但形状简单。各向同性（Br 0.45~0.60）便宜；各向异性（成型时加取向磁场，Br 0.60~0.75）贵。

**注意**：粘结磁体**不套 N/M/H/SH 那套耐温等级**（那是烧结的牌号体系），一般按 (BH)max 分档（如 5/8/10 MGOe）或直接给 Br + Hcj。

**三个真实好处**（外转子尤其明显）：

1. **整体磁环 / 多极**：无瓦片间隙 → 反电势更正弦、齿槽转矩小；省掉瓦片粘接和保持架。
2. **不导电、不锈**：电阻率比烧结高几个数量级 → 谐波涡流损耗小得多；不用镀层，少一道工序和一个失效模式。
3. **轻**：密度 5.0~6.2 vs 烧结 7.5，同体积轻 20%，转动惯量小。

**三个风险**：

1. **温度上限由粘结剂决定**：尼龙 ~120℃、PPS ~150~160℃、环氧 ~170~180℃。峰值堵转几分钟就能到 100~120℃，**尼龙体系余量很小**。
2. **膝点早**：峰值电流 3~5 倍额定时必须按最高工作温度校核退磁，冲击载荷场景不能省。
3. **磁性能只有烧结的 1/3~1/2**：小直径（30~40mm）+ 100W 连续，可能"磁钢厚到装不下"，得放大直径或回烧结。

**成本锚点**（60mm 级转子、磁钢 40~60g，我的估算）：

| 方案 | 磁钢成本 | 相对 |
|---|---|---|
| 铁氧体瓦片 | 0.5~1 元 | 基准 |
| 粘结钕铁硼磁环 | 4~10 元 | 5~10× |
| 烧结钕铁硼（含镀层/加工） | 12~25 元 | 20~40× |

**询价三问**：

1. 粘结剂是尼龙、PPS 还是环氧？最高连续工作温度多少？
2. 在"最高工作温度 + 峰值去磁电流"下的 Hknee 多少？要退磁曲线族，不要只给 20℃ 的那张。
3. 磁环与转子壳怎么固定（胶 / 过盈 / 包胶）？冲击工况保持力怎么验证？

**多极充磁**：粘结各向同性磁体可以做正弦充磁，别用阶梯充磁——波形优势就在这里。

### 7.4 铁氧体：便宜耐温，但低温才是危险点

- Br 随温度**升高而下降**（αBr ≈ −0.2%/℃）；Hcj 随温度**升高而上升**（βHcj ≈ +0.3~0.6%/℃）。
- 所以 **−40℃ 起动时 Br 最高、Hcj 最低**，这才是它的退磁危险点；和钕铁硼（高温危险）正好相反。
- 优点：极便宜、不锈、不导电（无涡流）、居里 450℃。
- 缺点：Br 低 → 磁钢厚 5~8mm、体积大；同样转矩下电机更重。

## 8. 采购与来料检验

**必须索取**：材质报告（Br / Hcj / Hcb / (BH)max）、退磁曲线、镀层报告、尺寸报告、RoHS/REACH。

**来料必检**：
- 尺寸与公差（关键配合面全检或高比例抽检）
- 表磁（高斯计，多点，记录位置）
- 外观（崩角、裂纹、镀层起泡、氧化）
- 首件做磁性能抽测（BH 仪或第三方）

**采购常识**：
- MOQ 通常按重量，小批量打样几十片也接，但单价会高 30~100%
- 交期：常规牌号 3~4 周，特殊牌号/高牌号 6~8 周
- 价格锚点：钕铁硼价格跟稀土（Pr-Nd、Dy、Tb）行情强相关，**报价有效期通常只有 1~2 周**
- 别在淘宝按"每片多少钱"比价，要按 **元/kg + 加工费** 比
- **粘结钕铁硼**：密度和磁性能批次波动比烧结大（密度 ±3%、Br ±5%），要按批抽检表磁；问清粘结剂体系，别只问 Br

## 附：一句话记住

> 磁钢选型的本质是：**在最高温度下，工作点不能掉到膝点以下。**
> 所有牌号、厚度、镀层的选择，都是在为这一句话服务。
