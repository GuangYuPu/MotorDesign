# 速查卡 · 标准与法规清单

> 只列**你实际会用到**的。每一条都标注"什么时候会有人问你要"。
> 版本号务必自行核对最新版，标准换版很频繁。

---

## 1. 基础性能与定额

| 标准 | 名称 | 什么时候用 |
|---|---|---|
| IEC 60034-1 | 旋转电机 定额和性能 | 定义工作制（S1/S2/S9）、温升限值、容差。**做铭牌和验收条件必用** |
| GB/T 755 | 旋转电机 定额和性能 | 国标版，内容大体对应 IEC 60034-1 |
| IEC 60034-2-1 | 损耗与效率试验方法 | 算效率、确定损耗分类。**报效率数据必须说明按哪个方法** |
| IEC 60034-2-2 | 变频供电电机的损耗与效率 | 变频器供电时怎么测效率。客户较真时会问 |
| IEC 60034-4 | 同步电机参数试验方法 | 测 Ld/Lq、Ke 的方法依据 |

## 2. 防护、冷却、安装、接线

| 标准 | 名称 | 什么时候用 |
|---|---|---|
| IEC 60034-5 / GB/T 4942 | 防护等级（IP） | 写 IP54 / IP65 时的定义依据。**IP 试验怎么做**也在这 |
| IEC 60034-6 | 冷却方式（IC 代号） | 铭牌上 IC411 / IC416 的来源 |
| IEC 60034-7 | 安装型式（IM 代号） | IM B3 / B5 / B35 |
| IEC 60034-8 | 端子标记与旋转方向 | 接线图、相序 |

## 3. 噪声与振动

| 标准 | 名称 | 什么时候用 |
|---|---|---|
| IEC 60034-9 | 噪声限值 | 客户投诉噪声时，先看有没有超标 |
| GB/T 10069 | 旋转电机噪声测定方法 | 怎么测、测点在哪、背景噪声怎么扣 |
| IEC 60034-14 | 振动（轴中心高 ≥56mm） | 振动烈度等级 A/B |
| GB/T 10068 | 轴中心高 ≥56mm 电机的机械振动 | 国标版 |
| ISO 1940-1 | 转子动平衡品质要求 | **动平衡 G 级怎么定**，做转子必用 |
| GB/T 2423.10 | 振动（正弦）试验 | 可靠性试验 |

## 4. 绝缘系统

| 标准 | 名称 | 什么时候用 |
|---|---|---|
| IEC 60034-18-1 | 绝缘系统 耐热性评定 | 定 B/F/H 绝缘等级的依据 |
| IEC 60034-18-21 | 散绕绕组 耐热性 | 小电机常用 |
| IEC 60034-18-31 | 成型绕组 耐热性 | |
| **IEC 60034-18-41** | **变频供电电机的绝缘系统（局部放电）** | **客户要"变频专用"时，这条就是门槛** |
| IEC 60034-18-42 | 变频供电电机的绝缘（耐电晕） | 与 -41 配套 |
| GB/T 11021 | 电气绝缘 耐热性分级 | B=130 / F=155 / H=180 |

## 5. 能效

| 标准 | 名称 | 什么时候用 |
|---|---|---|

## 8. 汽车行业（若做车用/车载）

| 项 | 说明 |
|---|---|
| IATF 16949 | 汽车质量管理体系，**供应商必须有** |
| VDA 6.3 | 过程审核 |
| AIAG-VDA FMEA | DFMEA / PFMEA 方法 |
| APQP | 产品质量先期策划 |
| PPAP | 生产件批准程序（**供应商交样必走的流程**） |
| MSA | 测量系统分析 |
| SPC | 统计过程控制 |

> 只要客户是车厂或 Tier1，这六件套就是入场券。**没有 PPAP 的样件，客户不会认。**

|---|---|

| ELV | 汽车报废回收指令 |

## 一张图记住优先级

```
做样机阶段   → IEC 60034-1（定额、温升）+ ISO 1940-1（动平衡）
报数据阶段   → IEC 60034-2-1（效率方法）+ 说清测试条件
客户验收阶段 → IEC 60034-5（IP）+ -9（噪声）+ -14（振动）
出口阶段     → IEC 60034-30-1（能效）+ UL/CE
车用阶段     → IATF 16949 + PPAP + FMEA
变频场景     → IEC 60034-18-41/-42  ← 最容易被忽略、最容易翻车
```

## 附：一句话记住

> 标准不是用来背的，是用来**在吵架时保护自己**的。
> 客户说"你这个不合格"，你能翻出标准第几条、用什么方法测、允差多少——这一刻你就是专家。
