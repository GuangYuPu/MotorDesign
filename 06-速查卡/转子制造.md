# 速查卡 · 转子制造

> 定子承担电机的一半功能，转子承担另一半。
> **转子的工艺链比定子长一倍**：冲压 → 叠压 → 车 → 磨 → 装磁钢 → 充磁 → 平衡，七道。
>
> **定子怕冲剪，转子怕磁桥。**
> **定子做错了是效率问题，转子做错了是安全问题。**

---

## 0. 定子 vs 转子：一张对照表

| 维度   | 定子        | 转子                      |
| ---- | --------- | ----------------------- |
| 铁芯   | 冲片叠压      | 冲片叠压（**常常是定子的边角料**）     |
| 精度关键 | 槽分度、内外圆同心 | **磁桥宽度**、外圆、动平衡         |
| 机加工  | 少，一般不车    | **必须车外圆 + 磨端面**         |
| 特有工艺 | 绕线、嵌线、浸漆  | 斜极、护套、磁钢装配、充磁、动平衡       |
| 失效后果 | 效率低、温升高   | **扫膛、飞裂、退磁**（安全 / 整机报废） |
| 工艺链  | 5~6 道     | **7~8 道**               |

## 1. 六类转子，制造逻辑完全不同

| 转子类型 | 铁芯成型 | 后续加工 | 典型场景 |
|---|---|---|---|
| **表贴式 SPM（普通）** | 冲片叠压 | 车外圆 → 粘磁钢 → 绑扎/灌封 | 风机、泵、伺服 |
| **表贴式 SPM（高速）** | 冲片叠压，**薄料 0.20~0.35mm** | 车外圆 → 粘磁钢 → **护套热套** | 高速主轴、离心压缩机 |
| **内嵌式 IPM** | 冲片叠压（**带磁桥，最复杂**） | 车外圆 → 压轴 → 插磁钢 → 灌胶/塑封 | 新能源驱动、伺服 |
| **实心转子** | 无（圆钢） | 车削 → 铣磁钢槽 → 粘磁钢 | 低成本小电机、部分高速 |
| **粉末冶金转子** | 压制烧结 | 少量机加工 | 小功率 BLDC、复杂形状 |
| **鼠笼转子（异步）** | 冲片叠压 | 压铸铝/铜 → 车外圆 | 异步电机 |

**结论**：凡是性能有要求的永磁电机，转子铁芯基本都是**冲压**的。实心转子只出现在成本优先或特殊场合。

## 2. 定转子套裁：最省钱的一招，但锁死两件事

### 做法

```
一条硅钢带
┌──────────────────────────────┐
│   ○  ○  ○  ○  ○  ○  ○  ○    │  ← 外圈冲定子片
│    ●  ●  ●  ●  ●  ●  ●       │  ← 定子中心孔那块料，冲成转子片
└──────────────────────────────┘
```

| 方式 | 材料利用率（行业经验值） |
|---|---|
| 只冲定子，中心孔当废料 | 30~40% |
| **定转子套裁** | **50~70%** |

级进模可以在一条料带上同时出定子片和转子片，**一次冲压出两个零件**。

### 代价一：转子外径被锁死

**转子外径必须小于定子内径，而且排样要套得进去。**

| 情况 | 能否套裁 |
|---|---|
| 内转子，常规比例 | 能，随便套 |
| **外转子** | **不能**（转子是杯形，只能单独冲） |
| 定子内径小、槽很深的扁平电机 | 套不进去，只能分开冲 |
| 转子外径接近定子内径（薄轭设计） | 套不进去 |

### 代价二：被迫用同一牌号

定子该用高牌号（低损耗），转子其实可以用低一档（转子铁损占比小）。

**套裁 → 被迫同牌号 → 省了材料但锁死了材料选型。**

不过多数情况下套裁还是赢：省下的材料费（20~30%）大于牌号降级省的钱（几个百分点）。**只有当转子体积占比特别大时才需要单独算。**

> 询价时一定要问一句：「转子片是套裁还是单独冲？套裁的话材料牌号是什么？」

## 3. 转子必须车外圆、磨端面：三个理由

| 工序 | 设备 | 典型公差 | 不做的后果 |
|---|---|---|---|
| **车外圆** | CNC 车 | 外圆 ±0.01~0.02，圆度 0.01 | 气隙不均 → 扫膛、单边磁拉力、噪声 |
| **磨端面** | 平面磨 | 垂直度 0.02，平行度 0.02 | 转子歪 → 气隙轴向不均 → 轴向力 |
| **轴孔** | 车/磨/铰 | H7 | 轴不同心 |

为什么冲不出来：

- 冲片外圆公差 ±0.05，还有毛刺
- 叠压后各片不同轴，累积偏差
- **气隙只有 0.3~0.5mm，公差要 ±0.02** —— 只有车能做到

### 一个容易被忽略的副作用

**车外圆会产生「翻边毛刺」**：刀刃把冲片边缘往外挤，翻边把相邻片短接 → 转子铁损上升。

对策：
- 控制切削参数（转速、进给、刀具锋利度）
- 车后清毛刺、补绝缘漆
- 关键场合用「精车 + 抛光」而不是「一刀切完」

## 4. IPM 磁桥：冲压工艺的极限战场

**磁桥（magnetic bridge）**：IPM 转子磁钢槽两端、连着外圆的那一点点薄钢。

```
        ┌─ 磁桥（0.5~1.5mm）
        ↓
  ╔═════╦═════════╗
  ║     ║ 磁钢槽  ║
  ╚═════╩═════════╝
```

### 它是设计里最尖锐的矛盾

| 功能 | 要求 | 冲突 |
|---|---|---|
| 机械 | 必须连住，否则高速离心力把外圆甩飞 | 要宽 |
| 磁路 | 必须饱和，否则磁钢磁通从桥里短路 | 要窄 |

所以宽度被卡在 **0.5~1.5mm**：

| 太宽 | 太窄 |
|---|---|
| 漏磁大 → 转矩掉、效率低 | 强度不够 → 高速飞裂 |

### 冲压难在哪

0.8mm 的桥，冲出来毛刺 0.05mm：

- **截面损失 6%**（0.05/0.8）
- 一个**应力集中源** → 高速疲劳裂纹的起源点
- 冲裁应力让桥部磁性能恶化：那个 0.5~1mm 的冲剪影响区，**在 0.8mm 的桥上就是整个桥**
- 细长冲头容易断，模具寿命短

**所以：IPM 转子冲片的供应商门槛，明显高于定子冲片。不是所有冲片厂都能做。**

### 必做的验证

**超速试验**：1.2 倍最高转速，保持 2 min，检查磁桥有无裂纹、外圆有无永久变形。

## 5. 转子叠压方式：和定子不完全一样

| 方式 | 铁损增量 | 适用 | 注意 |
|---|---|---|---|
| **自扣** | +3~10% | 通用中小转子 | **扣点必须避开磁桥和磁钢槽** |
| **铆接（拉杆/铆钉）** | +2~5% | 大转子、需可拆 | 占磁路截面，孔要避开磁路 |
| **焊接（激光/氩弧）** | +2~8% | 大转子 | 焊道避开磁桥 |
| **端板 + 拉杆压紧** | +0~2% | 高速、分段斜极 | 不破坏片间绝缘，但增加长度和重量 |
| **胶粘 / 自粘涂层** | +0~2% | 高端、低损耗 | 贵、周期长 |

> **转子叠压的位置约束比定子严格得多。**
> 定子上扣点落在磁路上，损失几个百分点；**转子上扣点落在磁桥上，直接废掉一个设计**。

## 6. 转子特有的四个工艺

### ① 斜极（降齿槽转矩 / 转矩脉动）

| 方式 | 做法 | 代价 |
|---|---|---|
| **分段斜极** | 叠 N 段（N=3~5），每段转一个角度 | 定位工装、段间压紧、轴向变长 |
| 连续斜极 | 逐片旋转叠压 | 工装复杂，量产少用 |
| **磁钢斜极** | 磁钢错位粘贴 | 最简单，但磁钢要分段 |

总斜极量通常取**一个定子槽距**。每段的机械转角 = 槽距 ÷ 段数。

段间必须**压紧 + 定位**（销/键），否则高速时松动、产生异响和轴向窜动。

### ② 护套 / 绑扎（高速防飞）

| 材料 | 特点 | 注意 |
|---|---|---|
| **不锈钢 304 / 316** | 最常用，热套 | **必须非磁！** 磁性钢套 = 给磁钢短路 |
| 钛合金 | 轻、强度高、贵 | |
| 碳纤缠绕 | 最轻、无涡流 | 导热差、成本高、工艺复杂 |
| 无纬带绑扎 | 便宜 | 只适合较低线速度 |

- 厚度 0.3~1.5mm
- 热套过盈量 0.05~0.15mm
- **热套温度必须低于磁钢的不可逆退磁温度**（或者干脆在充磁前热套）

### ③ 磁钢固定

| 方式 | 说明 | 坑 |
|---|---|---|
| 胶粘（环氧 / 厌氧） | 最常用 | 胶层 0.05~0.15mm；固化温度不能超磁钢工作温度 |
| 卡槽 | 机械定位，可靠 | 冲片要多一道槽，占磁路 |
| 灌胶 / 塑封 | 一体性好 | 模具费、返修难 |
| 护套压紧 | 高速必用 | 见上 |

**胶层太厚 → 等效气隙变大 → 转矩掉。** 这是 SPM 转子最常见的隐性损失。

### ④ 充磁时机

| 方式 | 优点 | 缺点 |
|---|---|---|
| **装配后整体充磁** | 装配时无磁、不吸铁屑 | 需要充磁夹具，场强要求 ≥3~5 倍 Hcj |
| 先充后装 | 不需要大夹具 | 吸铁屑、装配困难、易碰伤 |

**铁律：热套护套必须在充磁之前。** 200~300℃ 会把已充的磁退掉一部分。

## 7. 装配顺序：错一步就返工

### 正确顺序（SPM 高速转子）

```
① 冲片叠压（自扣/铆接）→ 称重核对片数
② 压轴 / 热套轴（过盈 0.02~0.05）
③ 车外圆 + 磨端面（以轴为基准）
④ 粘磁钢（环氧，控制胶层厚度）
⑤ 热套护套（200~300℃，此时磁钢未充磁，安全）
⑥ 动平衡（去重 / 配重）
⑦ 充磁（最后一步）
⑧ 表磁检测 + 反电势检测
```

### 三个致命顺序错误

| 错误 | 后果 |
|---|---|
| 先充磁，再热套护套 | 高温把磁钢退掉一部分，Ke 直接掉 |
| 先充磁，再动平衡 | 铁屑全吸上去，平衡做不准还清不干净 |
| 先粘磁钢，再车外圆 | 磁钢会被切削，且车削力能让它脱胶 |

**记住一条：凡是涉及「热」和「切削」的工序，都必须排在「充磁」和「装磁钢」之前。**

## 8. 轴向磁通的转子：又是另一套

**关键：轴向磁通转子背铁的磁通是「周向」的，和定子齿的「轴向」磁通垂直。**
所以**转子背铁的叠片方向，和定子齿正好相反**。

| 方案 | 说明 | 适合 | 涡流 |
|---|---|---|---|
| **实心钢盘** | 最常见，便宜，加工简单 | 低速、成本优先 | **大** |
| **扇形冲片轴向叠压** | 片平面 = 径向-周向，沿轴向叠；每片是扇形环 | 中高速 | 小 |
| **卷绕** | 带料卷成盘 | 中批 | 小 |
| **SMC** | 少见（盘状不需要三维磁路） | 特殊形状 | 中 |

### 三种方案的取舍

```
转速低、成本优先      → 实心钢盘（最省事，但涡流损耗要算清楚）
转速中高、效率敏感    → 扇形冲片轴向叠压（要排样、要叠压工装）
批量中等、想省模具    → 卷绕
形状复杂、带冷却结构  → SMC
```

**双转子结构额外要注意**：两侧气隙各 0.3~0.5mm，两个转子盘的**平行度**和**轴向定位**必须靠结构件保证，不能靠磁钢或胶层。轴向力不平衡会让转子贴死一侧。

## 9. 转子图纸必须标注的八句话

```
1. 叠压方式；扣点/焊道位置，明确"避开磁桥与磁钢槽"
2. 叠压系数 ≥ ___（称重法），并注明"称重核对片数"
3. 外圆公差、圆度、与轴的同轴度
4. 端面垂直度 / 平行度
5. 磁桥宽度 ___ ±0.05（关键尺寸，全检或高比例抽检）
6. 动平衡等级（G6.3 / G2.5）与残余不平衡量上限
7. 磁钢牌号、镀层、胶种、胶层厚度范围
8. 充磁方式与表磁范围（多点，注明测点位置）
```

> 第 5 条最关键。**磁桥宽度不写公差，等于把设计意图交给供应商。**

## 10. 问转子供应商的六句话（直接抄）

1. 「你们做过最窄的磁桥是多少？**量产稳定**在多少？」
2. 「磁桥部位毛刺控到多少？有没有断面/毛刺检测记录？」
3. 「转子片是套裁还是单独冲？套裁的话用什么牌号？」
4. 「叠压后车外圆，车削翻边怎么处理？会不会片间短路？」
5. 「分段斜极你们做过几段？段间定位精度多少？」
6. 「护套热套的温度和保温时间？对已装磁钢有没有影响？」

## 11. 供应商（起始名单，需自行核实）

**转子冲片**：与定子冲片厂重合（信质、通达、神力），但**要单独确认磁桥能力**。
**转子总成 / 磁钢装配**：多数电机厂自制；专门做转子总成的有卧龙、方正、精进电动等。
**护套**：不锈钢管材（304/316 精密管）+ 本地机加工；碳纤缠绕找复合材料厂。
**动平衡**：上海剑平、申岢（Schenck）、北京青云。
