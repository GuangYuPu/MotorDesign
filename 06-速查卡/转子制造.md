# 速查卡 · 转子制造

> 定子承担电机的一半功能，转子承担另一半。
> **转子的工艺链比定子长一倍**：冲压 → 叠压 → 车 → 磨 → 装磁钢 → 充磁 → 平衡，七道。
> **例外**：低成本外转子走「拉伸 → 整形 → 冲孔 → 粘磁钢」——没有叠压，也通常不车外圆（见 1.1）。
>
> **定子怕冲剪，转子怕磁桥。**
> **定子做错了是效率问题，转子做错了是安全问题。**

---

## 0. 定子 vs 转子：一张对照表

| 维度   | 定子        | 转子                      |
| ---- | --------- | ----------------------- |
| 铁芯   | 冲片叠压      | 冲片叠压（**常常是定子的边角料**）     |
| 精度关键 | 槽分度、内外圆同心 | **磁桥宽度**、外圆、动平衡         |
| 机加工  | 少，一般不车    | **必须车外圆 + 磨端面**         |
| 特有工艺 | 绕线、嵌线、浸漆  | 斜极、护套、磁钢装配、充磁、动平衡       |
| 失效后果 | 效率低、温升高   | **扫膛、飞裂、退磁**（安全 / 整机报废） |
| 工艺链  | 5~6 道     | **7~8 道**               |

## 1. 七类转子，制造逻辑完全不同

| 转子类型              | 铁芯成型                               | 后续加工                                | 典型场景             |
| ----------------- | ---------------------------------- | ----------------------------------- | ---------------- |
| **表贴式 SPM（普通）**   | 冲片叠压                               | 车外圆 → 粘磁钢 → 绑扎/灌封                   | 风机、泵、伺服          |
| **表贴式 SPM（高速）**   | 冲片叠压，**薄料 0.20~0.35mm**            | 车外圆 → 粘磁钢 → **护套热套**                | 高速主轴、离心压缩机       |
| **外转子杯形拉伸件（低成本）** | **拉伸冲压**（SPCC/SECC/SGCC，0.5~1.0mm） | 落料 → 拉伸 → 整形 → 冲孔 → 表面处理 → 压轴 → 粘磁钢 | 风机、泵、云台、小家电      |
| **内嵌式 IPM**       | 冲片叠压（**带磁桥，最复杂**）                  | 车外圆 → 压轴 → 插磁钢 → 灌胶/塑封              | 新能源驱动、伺服         |
| **实心转子**          | 无（圆钢）                              | 车削 → 铣磁钢槽 → 粘磁钢                     | 低成本小电机、外骨骼、低速大转矩 |
| **粉末冶金转子**        | 压制烧结                               | 少量机加工                               | 小功率 BLDC、复杂形状    |
| **鼠笼转子（异步）**      | 冲片叠压                               | 压铸铝/铜 → 车外圆                         | 异步电机             |

**结论**：凡是性能有要求的永磁电机，转子磁路件基本都是**冲压成型**的——内转子走冲片叠压，低成本外转子走杯形拉伸。实心转子只出现在成本优先或特殊场合。

### 1.1 外转子杯形拉伸件：1 元级成本段的另一套逻辑

**结构**：杯形拉伸壳（端面 + 筒壁）**既是结构件又是磁轭**；磁钢贴内壁；轴压入端面；定子在内、转子壳在外旋转。

**工艺链**（比冲片转子短）：落料 → 拉伸（1~2 道）→ 整形 → 冲孔/翻边 → 表面处理 → 压轴 → 粘磁钢/塑磁 → 动平衡 → 充磁。

**材料三选一**：

| 材料        | 牌号          | 锌层          | 相对成本    | 适用                       |
| --------- | ----------- | ----------- | ------- | ------------------------ |
| 冷轧板       | SPCC        | 无           | 最低      | 内部件；外露要另做涂漆/电泳           |
| **电解板**   | **SECC**    | 10~30 g/m²  | +10~20% | **外转子壳主流**：防锈 + 外观 + 可点焊 |
| 热镀锌       | SGCC        | 60~275 g/m² | +15~30% | 防锈最好，但锌层厚、冲压易掉锌、粘胶最差     |
| 镀铝锌 / 430 | AZ / SUS430 | —           | 高       | 户外、厨电等强防腐                |

**为什么低碳钢能当磁轭**：Bs 2.0~2.1 T，不比硅钢差；差的是电阻率（0.12~0.15 vs 0.5 μΩ·m）→ **涡流损耗高 3~4 倍**。所以它只对**低频 + 铁氧体 + 效率不敏感**的场合成立；一上 400 Hz 或钕铁硼高磁密，铁损和温升就把它否掉。

**成本结构（1 元级，我的估算）**：

| 项 | 金额 | 说明 |
|---|---|---|
| 材料 | 0.15~0.3 元 | 展开 Φ80~100 圆片、t=0.6、约 35 g |
| 冲压 | 0.15~0.3 元 | 25~63 T 冲床，班产几千 |
| 表面处理 | 0.05~0.15 元 | 镀锌 / 涂装 |
| 模具摊销 | 0.1~0.5 元 | 几千元模具 ÷ 1~5 万件 |
| **转子壳小计** | **约 0.5~1 元** | **不含轴、轴承、磁钢、装配** |

> **「1 元一个转子」必须先问含什么**：只算冲压壳，1 元合理；含磁钢的话，铁氧体瓦片 0.3~1 元、钕铁硼 2~5 元、轴承 0.3~1 元/个——**含钕铁硼的转子不可能 1 元**。

**六个和冲片转子完全不同的坑**：

1. **壁厚减薄**：拉伸后筒壁比料厚薄 10~20%，磁轭要按最薄处校核饱和；杯深/直径比 >0.5 通常要两道拉伸。
2. **圆度/同轴度**：杯口椭圆 → 气隙不均 → 噪声、扫膛。整形模 + 车口是常规手段。
3. **锌层与胶**：锌层上环氧附着差，要打磨/磷化/底涂；热镀锌最差。**这是外转子磁钢脱落的第一大原因。**
4. **锌层占磁路**：电解板 20/20 约 0.003 mm/面，可忽略；热镀锌 Z120~Z275 折合 0.017~0.038 mm/面，双面等效气隙 +3~8%，铁氧体弱磁时要算进去。
5. **薄壁模态**：0.5~0.6 mm 杯壁固有频率低，容易和 6/12 阶电磁力共振 → 嗡鸣；加筋或加厚。
6. **离心力**：100 W / 3,000 rpm / D60 → v≈9 m/s，胶接足够，不需要护套（见 1.2）。

**和硅钢冲片转子的取舍**：

| 项 | 杯形拉伸外转子 | 硅钢冲片内转子 |
|---|---|---|
| 磁轭 | SPCC/SECC 0.5~1.0 | 硅钢 0.35~0.5 |
| 铁损 | 高（电阻率低） | 低 |
| 频率上限 | ~400 Hz | 基本不受限 |
| 磁钢 | 铁氧体为主 | 钕铁硼为主 |
| 效率 | 60~80% | 80~92% |
| 壳成本 | 0.5~1 元 | 5~20 元 |
| 模具费 | 几千~1.5 万 | 3~30 万 |
| 起量 | 1k~10 万 | >1 万 |

**图纸要写的四句**：材料牌号 + 锌层重量（如 SECC 20/20）；最薄壁厚；圆度/同轴度/端面跳动；磁钢胶种 + 粘接前的表面处理（打磨/磷化）。

> 一句话：这是**用铁损换成本**的典型——风机/泵的间歇工况里，多花的电费几年也抵不上一次模具钱。

### 1.2 多快算「高速」：先算线速度，别看转速

**转速不是判据，线速度才是**——离心力只看转子表面速度：

```
v = π·D·n / 60  (m/s)        σ ≈ ρ·v²
```

烧结钕铁硼 ρ≈7500 kg/m³、抗拉 ~80 MPa → 裸磁钢在 **v≈100 m/s 就到极限**。这就是为什么 40~50 m/s 以上就要考虑机械保持。

| 线速度 v | 保持方式 | 对应 D=50mm 的转速 | 叫法 |
|---|---|---|---|
| < 40~50 m/s | 胶粘即可 | < 15k~19k rpm | 普通 SPM |
| 50~150 m/s | 不锈钢护套（非磁） | 19k~57k rpm | 高速 |
| 150~250 m/s | 碳纤 / 钛合金 + 磁钢分段 | 57k~95k rpm | 超高速 |
| > 250 m/s | 实心转子 / 特殊结构 | > 95k rpm | 工程极限 |

**三个口径要同时看**：

| 维度 | 门槛 | 后果 |
|---|---|---|
| 机械（v） | > 50 m/s | 磁钢飞裂风险 → 护套 |
| 电磁（f = n·p/60） | > 400 Hz | 铁损 ∝ f² → 薄料 0.20~0.35；>1 kHz 用 0.15~0.2（见 `硅钢与冲片.md` 2.1） |
| 热（风摩 ∝ n³） | 视冷却 | 自然冷却不够 → 油冷 / 真空 |

**所以第 1 节主表的分界**：普通 SPM ≈ v < 50 m/s（胶粘 + 绑扎够用）；高速 SPM ≈ v > 50 m/s（必须护套，且通常 f > 400 Hz，要配薄料）。

**换算举例**：D=60 mm、6,000 rpm → v = 18.8 m/s，4 极 → f = 200 Hz。这是关节模组的典型值——**机械上完全不算高速**，所以关节模组磁钢胶接就够、不需要护套；它的"高速"是控制意义上的，不是机械意义上的。

> 数字性质：由 σ=ρv² 与典型材料强度推算 + 行业经验分区，不同厂的安全系数和护套工艺会移动边界。

### 1.3 实心转子：为什么可以省掉叠片

**机理：转子坐标系里，基波磁场是直流的。**

- 定子铁心看到的是频率 f 的交变磁通 → 必须叠片。
- 转子同步跟着磁场转，磁钢与转子铁心相对位置不变 → **基波磁通不交变**，没有基波涡流和磁滞。
- 转子铁心真正承受的是**谐波**：定子齿谐波（≈ 槽数 × 转频）、绕组 MMF 谐波、PWM 载波谐波。幅值通常只有基波的百分之几（分布绕组）到 10% 量级（分数槽集中绕组），所以即使实心、电阻率低，损耗仍可控——**但分数槽时要单独核算**。

**但"可以接受"有边界**：

| 条件 | 安全区 | 危险区 |
|---|---|---|
| 电频率 | < 200~400 Hz | > 400 Hz，谐波涡流按 f^1.5~2 涨 |
| 绕组 | 整数槽分布绕组，谐波少 | 分数槽集中绕组，子谐波/齿谐波丰富 |
| 磁钢 | 铁氧体（电阻率高）或钕铁硼分段 | 整块钕铁硼 → 涡流温升 → 退磁 |
| 工况 | 连续、低速、散热好 | 堵转/冲击、低电感 + 大 PWM 纹波 |

**三个真实好处**（外骨骼这类场景）：

1. **无模具费**：车削 + 铣槽，适合几百~几千台的小批、多品种；拉伸杯要几千模具费，起量才划算。
2. **机械强度 / 抗冲击**：人机接触、跌倒冲击工况，实心比叠片耐造。
3. **导热好**：磁钢热量直接传到壳体，叠片转子的片间绝缘是热阻。

**三个代价**：

1. **漏磁磁桥**：磁钢槽之间是整块钢，要开隔磁槽/空气槽，否则磁通从桥里短路。
2. **局部热点**：涡流在磁钢槽边缘集中 → 胶老化、退磁；铣槽本身切断了部分涡流路径，比纯实心圆柱好。
3. **反电势谐波**：5/7 次比叠片转子明显 → 转矩脉动，人机交互的平顺性要测。

**验证三件套**：反拖法分离铁损/风摩；满载温升 + 停机后表磁复测（查退磁）；反电势 FFT 看 5/7 次。

> 一句话：实心转子不是偷工减料，是**用谐波损耗换模具费和强度**——前提是低频、谐波少、散热够。

## 2. 定转子套裁：最省钱的一招，但锁死两件事

### 做法

```
一条硅钢带
┌──────────────────────────────┐
│   ○  ○  ○  ○  ○  ○  ○  ○    │  ← 外圈冲定子片
│    ●  ●  ●  ●  ●  ●  ●       │  ← 定子中心孔那块料，冲成转子片
└──────────────────────────────┘
```

| 方式 | 材料利用率（行业经验值） |
|---|---|
| 只冲定子，中心孔当废料 | 30~40% |
| **定转子套裁** | **50~70%** |

级进模可以在一条料带上同时出定子片和转子片，**一次冲压出两个零件**。

### 代价一：转子外径被锁死

**转子外径必须小于定子内径，而且排样要套得进去。**

| 情况 | 能否套裁 |
|---|---|
| 内转子，常规比例 | 能，随便套 |
| **外转子** | **不能**（转子是杯形拉伸件，见 1.1） |
| 定子内径小、槽很深的扁平电机 | 套不进去，只能分开冲 |
| 转子外径接近定子内径（薄轭设计） | 套不进去 |

### 代价二：被迫用同一牌号

定子该用高牌号（低损耗），转子其实可以用低一档（转子铁损占比小）。

**套裁 → 被迫同牌号 → 省了材料但锁死了材料选型。**

不过多数情况下套裁还是赢：省下的材料费（20~30%）大于牌号降级省的钱（几个百分点）。**只有当转子体积占比特别大时才需要单独算。**

> 询价时一定要问一句：「转子片是套裁还是单独冲？套裁的话材料牌号是什么？」

## 3. 转子必须车外圆、磨端面：三个理由

> 指冲片叠压转子。杯形拉伸件的外圆靠模具与整形保证，只有精密/低噪声场合才补车（见 1.1）。

| 工序 | 设备 | 典型公差 | 不做的后果 |
|---|---|---|---|
| **车外圆** | CNC 车 | 外圆 ±0.01~0.02，圆度 0.01 | 气隙不均 → 扫膛、单边磁拉力、噪声 |
| **磨端面** | 平面磨 | 垂直度 0.02，平行度 0.02 | 转子歪 → 气隙轴向不均 → 轴向力 |
| **轴孔** | 车/磨/铰 | H7 | 轴不同心 |

为什么冲不出来：

- 冲片外圆公差 ±0.05，还有毛刺
- 叠压后各片不同轴，累积偏差
- **气隙只有 0.3~0.5mm，公差要 ±0.02** —— 只有车能做到

### 一个容易被忽略的副作用

**车外圆会产生「翻边毛刺」**：刀刃把冲片边缘往外挤，翻边把相邻片短接 → 转子铁损上升。

对策：
- 控制切削参数（转速、进给、刀具锋利度）
- 车后清毛刺、补绝缘漆
- 关键场合用「精车 + 抛光」而不是「一刀切完」

## 4. IPM 磁桥：冲压工艺的极限战场

**磁桥（magnetic bridge）**：IPM 转子磁钢槽两端、连着外圆的那一点点薄钢。

```
        ┌─ 磁桥（0.5~1.5mm）
        ↓
  ╔═════╦═════════╗
  ║     ║ 磁钢槽  ║
  ╚═════╩═════════╝
```

### 它是设计里最尖锐的矛盾

| 功能 | 要求 | 冲突 |
|---|---|---|
| 机械 | 必须连住，否则高速离心力把外圆甩飞 | 要宽 |
| 磁路 | 必须饱和，否则磁钢磁通从桥里短路 | 要窄 |

所以宽度被卡在 **0.5~1.5mm**：

| 太宽 | 太窄 |
|---|---|
| 漏磁大 → 转矩掉、效率低 | 强度不够 → 高速飞裂 |

### 冲压难在哪

0.8mm 的桥，冲出来毛刺 0.05mm：

- **截面损失 6%**（0.05/0.8）
- 一个**应力集中源** → 高速疲劳裂纹的起源点
- 冲裁应力让桥部磁性能恶化：那个 0.5~1mm 的冲剪影响区，**在 0.8mm 的桥上就是整个桥**
- 细长冲头容易断，模具寿命短

**所以：IPM 转子冲片的供应商门槛，明显高于定子冲片。不是所有冲片厂都能做。**

### 必做的验证

**超速试验**：1.2 倍最高转速，保持 2 min，检查磁桥有无裂纹、外圆有无永久变形。

## 5. 转子叠压方式：和定子不完全一样

> 仅适用于冲片叠压转子；杯形拉伸件没有叠压工序（见 1.1）。

| 方式            | 铁损增量   | 适用      | 注意               |
| ------------- | ------ | ------- | ---------------- |
| **自扣**        | +3~10% | 通用中小转子  | **扣点必须避开磁桥和磁钢槽** |
| **铆接（拉杆/铆钉）** | +2~5%  | 大转子、需可拆 | 占磁路截面，孔要避开磁路     |
| **焊接（激光/氩弧）** | +2~8%  | 大转子     | 焊道避开磁桥           |
| **端板 + 拉杆压紧** | +0~2%  | 高速、分段斜极 | 不破坏片间绝缘，但增加长度和重量 |
| **胶粘 / 自粘涂层** | +0~2%  | 高端、低损耗  | 贵、周期长            |
|               |        |         |                  |

> **转子叠压的位置约束比定子严格得多。**
> 定子上扣点落在磁路上，损失几个百分点；**转子上扣点落在磁桥上，直接废掉一个设计**。

## 6. 转子特有的四个工艺

### ① 斜极（降齿槽转矩 / 转矩脉动）

| 方式 | 做法 | 代价 |
|---|---|---|
| **分段斜极** | 叠 N 段（N=3~5），每段转一个角度 | 定位工装、段间压紧、轴向变长 |
| 连续斜极 | 逐片旋转叠压 | 工装复杂，量产少用 |
| **磁钢斜极** | 磁钢错位粘贴 | 最简单，但磁钢要分段 |

总斜极量通常取**一个定子槽距**。每段的机械转角 = 槽距 ÷ 段数。

段间必须**压紧 + 定位**（销/键），否则高速时松动、产生异响和轴向窜动。

### ② 护套 / 绑扎（高速防飞）

| 材料 | 特点 | 注意 |
|---|---|---|
| **不锈钢 304 / 316** | 最常用，热套 | **必须非磁！** 磁性钢套 = 给磁钢短路 |
| 钛合金 | 轻、强度高、贵 | |
| 碳纤缠绕 | 最轻、无涡流 | 导热差、成本高、工艺复杂 |
| 无纬带绑扎 | 便宜 | 只适合 **≤40~50 m/s**（再高预紧不够，见 1.2） |

- 厚度 0.3~1.5mm
- 热套过盈量 0.05~0.15mm
- **热套温度必须低于磁钢的不可逆退磁温度**（或者干脆在充磁前热套）

### ③ 磁钢固定

| 方式 | 说明 | 坑 |
|---|---|---|
| 胶粘（环氧 / 厌氧） | 最常用 | 胶层 0.05~0.15mm；固化温度不能超磁钢工作温度 |
| 卡槽 | 机械定位，可靠 | 冲片要多一道槽，占磁路 |
| 灌胶 / 塑封 | 一体性好 | 模具费、返修难 |
| 护套压紧 | 高速必用 | 见上 |

**胶层太厚 → 等效气隙变大 → 转矩掉。** 这是 SPM 转子最常见的隐性损失。

### ④ 充磁时机

| 方式 | 优点 | 缺点 |
|---|---|---|
| **装配后整体充磁** | 装配时无磁、不吸铁屑 | 需要充磁夹具，场强要求 ≥3~5 倍 Hcj |
| 先充后装 | 不需要大夹具 | 吸铁屑、装配困难、易碰伤 |

**铁律：热套护套必须在充磁之前。** 200~300℃ 会把已充的磁退掉一部分。

## 7. 装配顺序：错一步就返工

### 7.1 正确顺序（SPM 高速转子）

```
① 冲片叠压（自扣/铆接）→ 称重核对片数
② 压轴 / 热套轴（过盈 0.02~0.05）
③ 车外圆 + 磨端面（以轴为基准）
④ 粘磁钢（环氧，控制胶层厚度）
⑤ 热套护套（200~300℃，此时磁钢未充磁，安全）
⑥ 动平衡（去重 / 配重）
⑦ 充磁（最后一步）
⑧ 表磁检测 + 反电势检测
```

### 7.2 三个致命顺序错误

| 错误 | 后果 |
|---|---|
| 先充磁，再热套护套 | 高温把磁钢退掉一部分，Ke 直接掉 |
| 先充磁，再动平衡 | 铁屑全吸上去，平衡做不准还清不干净 |
| 先粘磁钢，再车外圆 | 磁钢会被切削，且车削力能让它脱胶 |

**记住一条：凡是涉及「热」和「切削」的工序，都必须排在「充磁」和「装磁钢」之前。**

### 7.3 表磁与反电势：怎么测、判什么

**分工**：表磁反映磁钢的**局部状态**（充磁饱满度、极间均匀性、是否退磁）；反电势是**整机磁路的结果**（磁钢 + 气隙 + 绕组 + 铁心）。两个都测才能定位问题：

- 表磁合格、反电势低 → 查气隙、定子、绕组、铁心
- 反电势合格、表磁不均 → 查局部退磁、充磁夹具
- 两个同时掉 → 磁钢批次或温度问题

**表磁（表面磁通密度）**

设备：高斯计/特斯拉计 + 霍尔探头（测法向 Bz 用轴向探头，测切向用横向探头），测距用非磁垫块或工装固定。

| 项 | 做法 |
|---|---|
| 测点 | 磁钢表面固定距离 0.5~1 mm；周向每极 5~9 点；轴向 2~3 段 |
| 记录 | 峰值 Bpk、极间偏差、周向波形、N/S 对称性 |
| 判据 | 对首件/标样：Bpk ±5%；极间偏差 ≤3~5%；波形无平顶、缺口 |
| 注意 | 远离磁场归零；磁钢温度 20±5℃；测距靠工装保证；铁磁件靠近会改变读数 |

**外转子磁环**：探头伸进杯内测气隙侧内壁；装配后钢壳会闭合磁路，表磁读数与自由状态不同——**装配后以反电势为准**。

**反电势（开路）**

| 方法 | 做法 | 适用 |
|---|---|---|
| **对拖** | 驱动电机拖动被测电机到设定转速，示波器测线电压 | 产线/实验室，可定量 |
| 惯性滑行 | 加速后断电，靠惯性滑行，采集衰减波形 | 没有拖动台时 |
| 手转 | 手转看相序、极性 | 只做定性 |

**测什么**：

- **Ke** = E_ll / n（V/krpm 或 V·s/rad）；测 2~3 个转速点验证线性
- **三相对称**：幅值偏差 ≤1~2%；相位 120°±2°
- **波形**：FFT 看 5/7 次，THD ≤3~5%（视设计）
- **温度修正**：Ke 随磁钢温度下降约 0.11%/℃，必须记录温度

设备：示波器（≥4 通道、差分探头）+ 拖动台/测功机 + 转速编码器；产线用反电势测试台（拖动 + 采集 + 判定，几秒/台）。

**判据表**：

| 项 | 建议判据 | 说明 |
|---|---|---|
| 表磁 Bpk | 标样 ±5% | 首件定标 |
| 极间偏差 | ≤3~5% | 充磁夹具/磁钢一致性 |
| Ke | 设计值 ±3~5% | 按温度修正后比 |
| 三相幅值不平衡 | ≤1~2% | 绕组/磁钢 |
| 相位偏差 | 120°±2° | |
| 反电势 THD | ≤3~5% | 斜极/磁钢分段可改善 |
| 线性度 | 两个转速点 Ke 偏差 ≤1% | 排除测量误差 |

**退磁复测**：高温/大电流试验后冷却到 20℃，复测表磁 + Ke，掉 >3~5% 判不可逆退磁。

**记录模板**：测点图 + 数值表 + 波形截图 + 转速 + 磁钢温度 + 判定。

> 数字性质：产线经验判据，具体阈值以客户图纸/技术协议为准。

## 8. 轴向磁通的转子：又是另一套

**关键：轴向磁通转子背铁的磁通是「周向」的，和定子齿的「轴向」磁通垂直。**
所以**转子背铁的叠片方向，和定子齿正好相反**。

| 方案 | 说明 | 适合 | 涡流 |
|---|---|---|---|
| **实心钢盘** | 最常见，便宜，加工简单 | 低速、成本优先 | **大** |
| **扇形冲片轴向叠压** | 片平面 = 径向-周向，沿轴向叠；每片是扇形环 | 中高速 | 小 |
| **卷绕** | 带料卷成盘 | 中批 | 小 |
| **SMC** | 少见（盘状不需要三维磁路） | 特殊形状 | 中 |

### 三种方案的取舍

```
转速低、成本优先      → 实心钢盘（最省事，但涡流损耗要算清楚）
转速中高、效率敏感    → 扇形冲片轴向叠压（要排样、要叠压工装）
批量中等、想省模具    → 卷绕
形状复杂、带冷却结构  → SMC
```

**双转子结构额外要注意**：两侧气隙各 0.3~0.5mm，两个转子盘的**平行度**和**轴向定位**必须靠结构件保证，不能靠磁钢或胶层。轴向力不平衡会让转子贴死一侧。

## 9. 转子图纸必须标注的八句话

```
1. 叠压方式；扣点/焊道位置，明确"避开磁桥与磁钢槽"
2. 叠压系数 ≥ ___（称重法），并注明"称重核对片数"
3. 外圆公差、圆度、与轴的同轴度
4. 端面垂直度 / 平行度
5. 磁桥宽度 ___ ±0.05（关键尺寸，全检或高比例抽检）
6. 动平衡等级（G6.3 / G2.5）与残余不平衡量上限
7. 磁钢牌号、镀层、胶种、胶层厚度范围
8. 充磁方式与表磁范围（多点，注明测点位置）
```

> 第 5 条最关键。**磁桥宽度不写公差，等于把设计意图交给供应商。**
