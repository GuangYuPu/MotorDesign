# 速查卡 · 电机工艺全链路

> 从一卷硅钢到一台能转的电机，中间有 **14 道工序**。
> 这张卡的作用：任何一道工序出问题，你知道找谁、问什么、代价多大。

---

## 全链路总览

```
① 材料入厂       硅钢卷 / 漆包线 / 磁钢毛坯 / 铝锭 / 圆钢
      ↓
② 冲片           级进模冲裁（或打样：激光/线切割）
      ↓
③ 叠压           自扣 / 焊 / 胶  →  铁芯
      ↓
④ 绝缘处理       插槽绝缘 / 槽楔（或涂敷）
      ↓
⑤ 绕线           机绕 / 手工绕  →  线圈
      ↓
⑥ 嵌线           手工 / 自动  →  定子绕组
      ↓
⑦ 整形 & 绑扎    端部整形、绑扎、相间绝缘
      ↓
⑧ 浸漆 / 灌封    VPI 真空压力浸漆 / 滴漆 / 灌封
      ↓
⑨ 机加工         轴、机壳、端盖、止口、轴承位
      ↓
⑩ 磁钢装配       涂胶 / 卡槽 / 护套  →  转子
      ↓
⑪ 充磁           整体充磁 / 分块充磁（后充磁优先）
      ↓
⑫ 动平衡         去重 / 配重
      ↓
⑬ 总装           轴承压装、气隙调整、端盖合装
      ↓
⑭ 测试           耐压 / 匝间 / 电阻 / 电感 / 反电势 / 空载 / 负载 / 振动噪声
```

### 分岔点：第 ③ 步之后，定子和转子走两条路

```
定子：④ 绝缘 → ⑤ 绕线 → ⑥ 嵌线 → ⑦ 整形绑扎 → ⑧ 浸漆 ─┐
                                                          ├→ ⑬ 总装 → ⑭ 测试
转子：⑨ 车外圆/磨端面 → ⑩ 磁钢装配 → ⑪ 充磁 → ⑫ 动平衡 ┘
```

**定子和转子的工艺链长度不一样**：定子 5~6 道，转子 7~8 道，因为转子多了车、磨、护套、平衡。
转子部分的细节见 `06-速查卡/转子制造.md`。

## 逐工序：关键参数 / 常见坑 / 打样渠道

### ② 冲片

| 项 | 内容 |
|---|---|
| 关键参数 | 毛刺 ≤0.05mm；尺寸公差 ±0.02；同轴度 0.03；叠压系数 0.95~0.97 |
| 常见坑 | 齿宽小→塌角；毛刺刺穿片间绝缘；冲剪应力使铁损上升 20~50% |
| 打样 | 淘宝/1688「硅钢片 线切割 定制」，传 DXF，2~3 天，几十~几百元 |
| 量产 | 常州/宁波/台州冲片厂，开级进模 3~30 万，4~8 周 |

### ③ 叠压

| 项 | 内容 |
|---|---|
| 方式 | 自扣（+3~10% 铁损，最便宜）/ 氩弧焊（+3~8%）/ 激光焊（+2~5%，薄料首选）/ 胶粘或自粘涂层（+0~2%，最贵）|
| 关键参数 | 叠压系数；焊道位置必须避开齿部；扣点不能落在磁路上 |
| 常见坑 | 焊道打进齿部 → 局部涡流 → 热点 → 绝缘老化 |
| 图纸要写 | "焊道位置避开齿部，焊缝宽 ≤___mm，不得有穿透性烧蚀" |

### ④ 绝缘处理

| 项 | 内容 |
|---|---|
| 材料 | NMN（聚酯薄膜+无纺布）、DMD、聚酰亚胺（PI）；厚度 0.2/0.25/0.3 mm |
| 关键参数 | 槽绝缘厚度直接吃掉槽满率；端部相间绝缘；槽口保护 |
| 常见坑 | 槽绝缘太薄 → 嵌线破漆 → 对地击穿；太厚 → 槽满率不够 |
| 涂敷 | 环氧粉末涂敷（流化床/静电喷涂）用于防腐和端部绝缘 |
| 供应商 | 艾伦塔斯 ELANTAS、苏州巨峰、浙江荣泰、杜邦、3M |

### ⑤⑥ 绕线 & 嵌线

| 项 | 内容 |
|---|---|
| 关键参数 | 匝数、线径、并绕根数、跨距、端部长度、相电阻平衡（≤2%）|
| 常见坑 | 拉力过大 → 漆膜损伤；匝数错 → 反电势偏差；端部过长 → 铜耗和风阻增加 |
| 自动化 | 嵌线机一次性投入大（几十万~百万），批量 >5 万/年才划算 |
| 打样 | 手工绕，找本地小厂或自己绕；绕线机几万元可买 |

### ⑧ 浸漆 / 灌封（最容易被低估的一道）

| 项 | 内容 |
|---|---|
| 方式 | 滴漆（便宜，填充率低）/ **VPI 真空压力浸漆**（主流，填充率高）/ 灌封（导热+固定）|
| 关键参数 | 挂漆量、填充率、固化曲线、漆的耐温等级（必须 ≥ 绝缘等级）|
| 常见坑 | 浸不透 → 端部振动磨损 → 匝间短路；漆与漆包线不兼容 → 漆膜溶胀 |
| 灌封注意 | 导热系数（1~3 W/m·K）、CTE 与铜/铁匹配、固化收缩、可返修性 |

### ⑨ 机加工

| 项 | 内容 |
|---|---|
| 关键参数 | 轴承位公差（j5/js6 常见）、同轴度、垂直度、止口配合 |
| 常见坑 | 同轴度差 → 气隙不均 → 扫膛 + 单边磁拉力 + 噪声 |
| 材料 | 轴 45 钢 / 40Cr（调质）；机壳 压铸 ADC12 / 拉伸铝 / SMC |

### ⑩ 磁钢装配

| 项 | 内容 |
|---|---|
| 方式 | 涂胶（环氧结构胶）/ 卡槽 / 不锈钢护套 / 碳纤绑扎 |
| 关键参数 | 胶层厚度 0.05~0.15mm、拉剪强度、固化温度不能超过磁钢工作温度 |
| 常见坑 | 胶层太厚 → 磁路气隙变大 → 转矩掉；固化不充分 → 高速甩脱 |
| 必做验证 | 高低温循环 + 超速试验（1.2 倍最高转速，保持 2 min）|

### ⑪ 充磁

| 项 | 内容 |
|---|---|
| 方式 | 整体充磁（装配后）/ 分块充磁（先充后装，危险，易吸附异物）|
| 关键参数 | 充磁场强（≥ 3~5 倍 Hcj）、充磁方向、多极充磁的极对齐 |
| 常见坑 | 充磁不足 → 反电势偏低；多极充磁偏 → 转矩脉动大、噪声 |
| 检验 | 表磁扫描（多点）、反电势三相对比 |

### ⑫ 动平衡

| 项 | 内容 |
|---|---|
| 标准 | ISO 1940-1，一般电机 G6.3，精密/高速 G2.5 或 G1 |
| 关键参数 | 剩余不平衡量 U = e × m（e 为许用偏心距）|
| 常见坑 | 只做单面平衡（长转子必须双面）；去重位置影响磁路 |

### ⑬ 总装

| 项 | 内容 |
|---|---|
| 关键参数 | 气隙周向均匀度（≤±10%）、轴承预紧、端盖同轴 |
| 常见坑 | 气隙不均 → 单边磁拉力 → 振动 + 轴承早期失效 |
| 检验 | 周向 4~8 点气隙测量、盘车手感、空载电流 |

### ⑭ 测试

| 项 | 内容 |
|---|---|
| 必做 | 耐压、绝缘电阻、匝间冲击、三相电阻/电感平衡、反电势、空载电流、振动、噪声 |
| 抽做 | 温升、效率 map、堵转、超速、盐雾、温循、IP |
| 关键 | **测试记录必须留档**，出问题时的第一手证据 |

## 打样 vs 量产：两条完全不同的路

| 环节 | 打样（1~50 台） | 量产（>1000 台） |
|---|---|---|
| 冲片 | 激光 / 线切割 | 级进模 |
| 叠压 | 手工叠 + 临时夹具 / 激光焊 | 自扣 / 焊 |
| 绕线嵌线 | 手工 | 机绕 + 自动嵌线 |
| 浸漆 | 手工浸 / 外协 | VPI 产线 |
| 机壳 | CNC 铝块 | 压铸模 |
| 磁钢 | 现货牌号 + 手工粘 | 定制 + 自动点胶 |
| 成本 | 单台几千~几万 | 单台几十~几百 |
| 目的 | 验证原理和尺寸链 | 验证一致性和良率 |

> **最危险的思维**：拿打样的性能和成本，去推量产的结论。
> 打样阶段铁损偏低（激光切割虽然差，但没开模应力，且是单片测量），一致性没暴露，成本高 5~10 倍。

## 一道工序出问题，怎么快速定位

| 现象 | 优先怀疑的工序 |
|---|---|
| 反电势偏低 / 三相不平衡 | ⑪ 充磁、⑤ 绕线匝数、⑩ 磁钢错装 |
| 耐压不过 / 匝间短路 | ④ 槽绝缘、⑤ 绕线拉力、⑥ 嵌线破漆 |
| 温升偏高 | ② 铁损（材料/冲剪）、⑤ 线径公差偏下、⑧ 浸漆不透、⑬ 气隙不均 |
| 振动大 | ⑫ 动平衡、⑨ 同轴度、⑬ 气隙不均、⑩ 磁钢配重 |
| 噪声大（阶次啸叫） | ⑬ 气隙不均、⑪ 充磁偏心、② 齿部尺寸偏差、设计侧极槽配合 |
| 扫膛 | ⑨ 同轴度、⑬ 气隙、轴承游隙、热膨胀 |
| 磁钢脱落 | ⑩ 胶层/固化、表面处理、离心力 |
