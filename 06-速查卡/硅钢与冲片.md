# 速查卡 · 硅钢与冲片

> 电磁设计里最容易被低估的一块：**你仿真里那个"0.35mm 硅钢"，和产线上那个冲出来的铁芯，不是同一个东西。**

---

## 1. 牌号怎么读

```
50 W 470
│  │  └── P1.5/50 铁损 × 100，单位 W/kg（1.5T / 50Hz 下）
│  └───── W = 无取向电工钢（G 表示高磁感取向）
└──────── 厚度，单位 0.01 mm → 50 = 0.50 mm
```

**宝钢系**：`B50A470` = B（宝钢）+ 50（0.50mm）+ A（无取向）+ 470（铁损 4.70 W/kg）。逻辑相同。

**关键理解**：数字越大，铁损越高、价格越便宜、**磁感通常越高**。

> **选材的本质是权衡**：要低铁损就得付更高牌号的钱，同时**磁感会掉**，意味着同样转矩要更多匝数或更长铁芯。高效电机常在这两者之间反复试。

## 3. 五个必须知道的"非理想效应"

### ① 冲剪应力（小电机杀手）

冲裁边缘 **0.5~1.0 mm** 范围内，晶粒被破坏，铁损上升 **20~50%**，磁感下降。

- **齿宽越小，这个相对影响越大。** 齿宽 3 mm 的电机，边缘影响区能占到齿宽的 1/3。
- 高牌号（薄料、低损耗）对剪切应力**更敏感**。
- 结论：**小电机用超高牌号，收益可能被冲剪应力吃掉一半。** 这是很多人算不明白的地方。

**对策**：去应力退火（750~800℃，保温 1~2h），可恢复部分铁损；但会变形、需重新叠压，量产少用。或者选"抗应力"牌号（如宝钢的 AH/AK 系列，需向厂家确认）。

### ② 叠压系数

| 叠压方式 | 叠压系数 | 备注 |
|---|---|---|
| 涂层 + 自扣 | 0.95~0.97 | 主流 |
| 涂层 + 焊接 | 0.95~0.97 | 焊道影响局部 |
| 自粘涂层 | 0.96~0.98 | 最紧凑，成本高 |
| 无涂层 | 0.97~0.98 | 片间短路，不可用于交流 |

**仿真里填的叠压系数，必须和产线实际工艺对应。** 填 0.98 而实际是 0.95，铁芯有效长度就差 3%，转矩直接差 3%。

### ③ 涂层

| 涂层 | 耐温 | 绝缘性 | 焊接性 | 用途 |
|---|---|---|---|---|
| C3 | 一般 | 一般 | 好 | 通用 |
| C4 | 中 | 好 | 中 | |
| C5 | 高 | 好 | 好 | 高效电机主流 |
| C6 | 最高 | 最好 | 中 | 高端 |
| 自粘涂层 | 中 | 好 | 差 | 低损耗叠压 |

### ④ 毛刺

- 常规要求 **≤ 0.05 mm**，精密 **≤ 0.02 mm**。
- 毛刺会刺穿片间绝缘 → 局部涡流 → 铁损上升 + 局部过热。
- 图纸上要写"毛刺方向朝外"或"毛刺≤0.03"，否则供应商按自己的习惯做。

### ⑤ 各向异性

无取向硅钢也有轧向/横向差异（铁损差 10~20%）。冲片排样时如果齿部方向不一致，会造成磁性能不均。大批量排样要跟模具厂确认。

## 4. 冲片加工方式对比

| 方式           | 精度         | 单件成本  | 周期       | 适用批量        | 对磁性能影响           |
| ------------ | ---------- | ----- | -------- | ----------- | ---------------- |
| **激光切割**     | ±0.05~0.1  | 高（小批） | 1~3 天    | 打样 1~50 件   | 热影响区 + 毛刺，铁损明显上升 |
| **线切割（慢走丝）** | ±0.01      | 很高    | 3~7 天    | 打样 1~20 件   | 无应力、无毛刺，**质量最好** |
| **线切割（中走丝）** | ±0.02      | 中高    | 2~5 天    | 打样 10~100 件 | 较好               |
| **复合模**      | ±0.02      | 低     | 开模 2~4 周 | 1k~5 万      | 好                |
| **级进模**      | ±0.01~0.02 | 最低    | 开模 4~8 周 | > 1 万       | 好，带自扣叠压          |

**打样铁律**：**样机阶段不要开模。** 激光或线切割做 2~3 轮，把尺寸链、公差、磁性能全部验证完，再开模。

## 5. 叠压方式：五种做法的完整对比

> 铁芯是**叠**起来的，不是一整块。所有叠压方式都是在「把它绑紧」和「别让它片间短路」之间做取舍。
> 这一步直接决定：铁损多少、叠压系数多少、要不要多一道工序、多花多少钱。

### 5.1 总表

| 方式 | 铁损增量 | 结构强度 | 成本 | 批量适应性 | 叠压系数 | 适用料厚 | 典型场景 |
|---|---|---|---|---|---|---|---|
| **自扣（叠铆 / interlock）** | +3~10% | 好 | **最低**（模内完成，零附加工序） | **最好** | 0.95~0.97 | 0.35~0.65 | 绝大多数中小型电机：家电、风机、泵、通用伺服 |
| **氩弧焊（TIG）** | +3~8% | **最好** | 低 | 好 | 0.94~0.96 | 0.35~0.65 | 大铁芯、振动大、需高结构强度 |
| **激光焊** | +2~5% | 好 | 中 | 好 | 0.94~0.96 | **0.20~0.35** | 薄料：新能源驱动、关节模组、高性能伺服 |
| **胶粘 / 自粘涂层** | **+0~2%** | 看胶 | **高** | 差（要固化、要工装、周期长） | **0.96~0.98** | 0.20~0.35 | 铁损极敏感、小批量、多品种 |
| **铆接（铆钉 / 穿心）** | +2~5% | 好 | 低 | 中 | 0.95~0.97 | 任意 | 大铁芯、需可拆卸返修、样机试制 |

> **数字性质：行业经验值**，基准是「同材料、同尺寸、理想无极叠压」。不同厂、不同扣点/焊道设计之间能差 2 倍。
> **必须用你自己产线的样件实测标定**，别拿这张表去答辩，拿它去设计提问清单。

### 5.2 为什么自扣会加铁损：三重影响，不止涡流

**① 片间短路 → 局部涡流**（最直接）
扣点处金属对金属接触，涂层被挤破，形成贯穿多片的导电通路。等效于这些位置「片变厚了」，涡流损耗上升。

**② 截面减小 → 局部磁密升高**
扣点凹进去，那段材料基本不导磁。
- 若落在齿部或高磁密轭部，局部磁密可升 5~15%
- 一旦推进饱和，铁损、转矩、噪声一起变差
- **这是三项里唯一能在设计阶段完全控制的**

**③ 机械应力 → 局部磁导率下降**
扣压是塑性变形，和冲剪应力同源，只是范围更集中。

### 5.3 三条能直接写进图纸的对策

1. **扣点布置在低磁密区**：轭部外缘、槽底下方、齿根以外。**绝不放在齿身中部。**
2. **少而分散**：中小铁芯 4~8 个/片；能用 4 个就别用 8 个。
3. **错位排列**：不要一条直线贯穿整个叠厚，否则形成一根连续的「短路柱」，涡流顺着它走。相邻片错开 30~60°。

焊接同理：**焊道贴外圆（轭部外缘，磁密最低），宽度尽量窄，条数尽量少。**

### 5.4 图纸上必须写的四句话

```
1. 叠压方式：自扣 / 氩弧焊 / 激光焊 / 胶粘（必须写明，不许留空）
2. 焊道或扣点位置：避开齿部与高磁密轭部，具体位置见示意图
3. 焊缝宽度 ≤ ___ mm，不得有穿透性烧蚀
4. 叠压系数 ≥ ___（称重法实测），毛刺 ≤ ___ mm
```

> 只写「叠压牢固」等于没写。不指定，供应商一定按最省事的做法来。

### 5.5 怎么选：三步决策

```
第一步  料厚？
├─ ≤0.30mm  → 自扣变形占比大、损耗增量更高 → 优先 激光焊 / 胶粘
└─ ≥0.35mm  → 自扣可用，且是最经济的选择

第二步  铁损敏感度？
├─ 效率/温升是主要指标（关节模组、伺服、EV）→ 激光焊 或 胶粘
└─ 成本是主要指标（家电、风机、泵）→ 自扣

第三步  批量？
├─ >5 万/年  → 自扣（模内完成，少一道工序就是省钱）
├─ 1~5 万/年 → 自扣 或 激光焊
└─ <1 万/年  → 激光焊 / 胶粘（省模具复杂度，改型快）
```

### 5.6 一个反直觉的事实

**自扣的铁损最高，却是用量最大的叠压方式。**

不是大家不在乎铁损，而是：
- 它在**模具里一次完成**：不要第二道工序、不要工装、不要固化时间
- 省下的人工、场地、周期，通常比 3~8% 的铁损更值钱
- 只有铁损能**直接换算成温升或效率罚款**的场合（关节模组、伺服、EV），才值得为它多花钱

**段位在这**：不是「知道自扣有损耗」，而是「知道这次 +8% 我能不能接受、不能接受换什么、换完多花多少钱、多等几天」。

| 需求 | 渠道 | 说明 |
|---|---|---|
| 1~10 片，快速验证 | 淘宝 / 1688 搜"硅钢片 线切割 定制" | 上传 DXF，2~3 天，几十到几百元 |
| 10~100 片 | 同上或本地模具厂 | 单价降下来 |
| 开模 | 常州 / 宁波 / 台州 冲片厂 | 需要谈模具费、寿命、叠压方式 |
| 特殊材料 | 宝钢 / 太钢 / 首钢 经销商 | 小批量可能要整卷买（几百 kg） |

> 淘宝打样**只用于验证"能不能做出来"和"尺寸对不对"**。它的铁损和一致性不能代表量产，别拿它的性能数据做设计定型依据。

## 7. 关键问题清单（问供应商，直接抄）

1. 你们的叠压系数实测多少？用什么方式测的？
2. 毛刺控制在多少？有没有毛刺检测记录？
3. 自扣的扣点位置怎么定？会不会落在磁路上？
4. 焊接的话，焊道位置和宽度怎么保证？
5. 冲裁后做不做去应力退火？做了铁损能降多少？
6. 模具寿命多少冲次？磨损后怎么修？修一次多少钱？
7. 最小齿宽能做到多少不出塌角？
8. 同轴度/垂直度能保证到多少？
9. 你们默认用哪种叠压方式？我们这种料厚你们推荐哪种？为什么？
10. 扣点/焊道的位置是你们定还是要我们指定？上一批是怎么布置的？

## 8. SMC（软磁复合材料）

- 三维磁路、轴向磁通、复杂形状的理想材料（可模压成型，不用冲片叠压）。
- 缺点：**磁导率和饱和磁感低**（Bs 约 1.8~2.0 T，但有效磁感常只有 1.2~1.5 T），**铁损高**（尤其低频）。
- 适合：高频、3D 磁路、小批量复杂形状。
- 供应商：东睦股份、Höganäs。
